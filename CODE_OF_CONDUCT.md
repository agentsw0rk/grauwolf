# Code of Conduct

grauwolf follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Everyone who takes part in the project – in issues, pull requests, discussions, chats, meetings and
events – is expected to follow it: be respectful, welcoming and constructive, and do not harass or
exclude anyone.

## Reporting

If you experience or witness unacceptable behaviour, please report it to the maintainers at
`<conduct contact e-mail>`. Reports are handled confidentially. If a maintainer is involved, or you
do not want to contact the maintainers, you can contact the CNCF Code of Conduct Committee at
<conduct@cncf.io> (see the
[CNCF incident resolution procedures](https://github.com/cncf/foundation/blob/main/code-of-conduct/coc-incident-resolution-procedures.md)).

The maintainers enforce this code of conduct; see [GOVERNANCE.md](GOVERNANCE.md).
