# Logo

| File | Content | Use |
|---|---|---|
| `grauwolf-logo-sheet.png` | original sheet with all variants (1536 × 1024) | source |
| `grauwolf-logo.png` | wolf head with the word mark "grauwolf" on a cream background (1200 × 435) | where a solid background fits |
| `grauwolf-logo-light.png` | the same mark, dark on a transparent background | header of the README in light mode |
| `grauwolf-logo-dark.png` | the same mark, light (`#ECE8E1`) on a transparent background, blue unchanged | header of the README in dark mode |
| `grauwolf-icon.png` | wolf head alone, light background | e.g. favicon, avatar |
| `grauwolf-icon-dark.png` | wolf head, light on a dark square | e.g. app icon, social preview |

The crops are cut from the sheet. The transparent variants come from the same crop: the opacity of
each pixel follows from its distance to the background (`#FDF8F2`) relative to the typical ink
(`#303435`) or the blue (`#7EB7D0`); for dark mode the ink is recolored light.
When the logo changes, replace the sheet and generate the variants again.
