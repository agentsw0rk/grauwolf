# ADR-0012: Project name grauwolf

- **Status:** Accepted (User, 2026-11-06)
- **Date:** 2026-11-06

## Context
The project needs its own short name.

## Decision
Name grauwolf, crate prefix `grauwolf-`.

## Consequences
Independent further development without name conflicts.

## Addendum: spelling (User, 2026-11-09)
The project name is always written in lowercase: `grauwolf` – in docs, comments, messages and examples, even at the start of a sentence. The former long name is dropped.
